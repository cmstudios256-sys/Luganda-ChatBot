Okwegeranya

Learning & fine-tune data

Every thumbs-up is a good answer; every thumbs-down with a correction becomes a preference pair. Export turns this chat history into training files for finetune/build_dataset.py.

Download .jsonl

How the loop works
1. Chat normally — natives correct answers with 👎 + rewrite.
2. Export → finetune/data/exported/*.jsonl.
3. python finetune/build_dataset.py merges it with the seed set and a Luganda corpus, dedupes and splits.
4. python finetune/train_lora.py --config finetune/configs/lora_sunflower14b.yaml trains an adapter.
5. python finetune/eval.py scores chrF + a native-speaker rubric.
